# About Agent Plan Team

## What is the difference between Agent Plan Team and Coding Plan Team?

Agent Plan Team is a new subscription package upgraded from Coding Plan Team. The differences are as follows:

|Comparison |Agent Plan Team |Coding Plan Team |
|---|---|---|
|Primary focus |A new subscription package for large model services focused on Agent scenarios, expanding into multimodal capabilities and Harness. |A subscription package for coding model services focused on coding scenarios for enterprise customers. |
|Models |Language models, embedding models, and visual models (image and video generation models) |Language models and embedding models |
|Harness |BytePlus Searchinfinity |/ |
|Base URL and API Key |Obtain the dedicated Base URL and API Key from the [Agent Plan Team console](https://ai.byteplus.com/ark/region:ap-southeast-1/subscription/agent-plan-enterprise?agentMode=close). |Obtain the dedicated Base URL and API Key from the [Coding Plan Team console](https://ai.byteplus.com/ark/region:ap-southeast-1/subscription/coding-plan-enterprise?agentMode=close). |
|Subscription tiers |4 tiers to choose from |2 tiers |
|Billing |Usage is deducted in Agent Fuel Points (AFP), with clearly visible quota usage. |Estimated model request count |
