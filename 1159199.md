# Monitoring

In the lower\-left corner of the console, select [Usage Statistics](https://ai.byteplus.com/ark/region:ap-southeast-1/usageTracking) to view invocation usage statistics for the corresponding project under the primary account. You can also view usage statistics by category, including online inference and batch inference.

Details:

* Online inference supports viewing usage at daily or hourly granularity.

   * Current project usage: total number of tokens invoked, total input tokens, and total output tokens. Usage can also be broken down by preset inference endpoint or custom inference endpoint.

   * Usage for a specified endpoint: total usage, model input usage, and model output usage.

* Batch inference supports viewing usage by inference task and inference endpoint dimensions.

   * Total usage, inference task, and inference endpoint.

   * Endpoint details: total usage, model input usage, and model output usage.

* Inference outsourcing supports viewing the number of invocations and tokens at daily or hourly granularity.
