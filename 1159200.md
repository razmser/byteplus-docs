# Model Activation Management

# Overview

The Model Activation Management page displays the activation status, free quota consumption, inference input/output pricing, LoRA fine\-tuning pricing, full fine\-tuning pricing, and model rate limits of the product. It also allows you to enable/disable services and view the connection documents of models.

![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/47e0c86cca0041a497e93bff31fffda0~tplv-goo7wpa0wc-image.image)

## Activation status

|Status |Description |
|---|---|
|Not activated |The model service is not activated. Each model provides some calls free of charge that are available before activation. After the free quota is used up, you can activate the model on the [Activation Management](https://ai.byteplus.com/ark/region:ap-southeast-1/openManagement) page for paid use. After activation, any remaining free quota is consumed first. |
|Activated |The model service has been activated. |

## Free quota

Each model provides some calls free of charge. After the free quota is used up, you can activate the model on the [Activation Management](https://ai.byteplus.com/ark/region:ap-southeast-1/openManagement) page for paid use. After activation, any remaining free quota is consumed first.

## Model rate limits

The call limits for each base model under each account are requests per minute (RPM) and tokens per minute (TPM).

> **tip**

1. > All inference endpoints of the same base model share the rate limits of the base model.

2. > The rate limits contain model calls in postpaid billing by token but not purchased model units.

3. > The rate limits of each inference endpoint can be specified on the inference endpoint details page.
