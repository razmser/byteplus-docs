# Model releases

This document summarizes new model releases for Agent Plan Team and provides links to the corresponding documentation.

## 202611

|Model |Description |How to use |
|---|---|---|
|seed\-2.0\-mini |A lightweight, balanced omnimodal model that supports understanding and cross\-modal reasoning across text, images, speech, and video. It streamlines reasoning to improve response efficiency and runtime stability, and strengthens support for multiple languages, including less widely used languages. It is suitable for general\-purpose, lightweight multimodal analysis. |[Quick start guide](agent-plan-enterprise-get-started.md) |
|seed\-2.0\-lite |A lightweight omnimodal model for enterprise deployment at scale, supporting joint cross\-modal understanding of text, images, speech, and video. It integrates joint audio\-video analysis, temporal retrieval in long videos, comprehensive audio analysis, code development, intelligent agents, and closed\-loop GUI operations. It is suitable for omnimodal inference workloads at high volume. |[Quick start guide](agent-plan-enterprise-get-started.md) |
|deepseek\-v4\-flash |DeepSeek V4 Flash is an efficient model for low\-latency inference, coding, and tool calls. It supports a 1M context window and outputs of up to 384K, allows thinking to be enabled or disabled, and is compatible with the Chat Completions, Responses, and Messages protocols. Implicit caching improves efficiency when context is reused. It is suitable for highly concurrent online inference, long\-form text generation, and fast coding assistance. |[Quick start guide](agent-plan-enterprise-get-started.md) |
|dola\-seed\-2.1\-turbo |A fully featured, low\-cost, low\-latency version for production at scale. It is suitable for coding, agent, and multimodal understanding tasks that require consistently handling large volumes of online requests, and for enterprise deployments that prioritize cost, throughput, and batch requests. |[Quick start guide](agent-plan-enterprise-get-started.md) |
|deepseek\-v4\-pro |Designed for production agents, complex reasoning, code generation, and long\-document analysis. It supports a 1M context window, outputs of up to 384K, a thinking toggle, and multiple reasoning effort levels. |[Quick start guide](agent-plan-enterprise-get-started.md) |
|deepseek\-v4.1\-flash |Reinforcement learning based on self\-feedback further improves complex programming and complete project development, with better performance in intent\-driven programming scenarios such as game development and 3D modeling. It also reduces task runtime and output length, improving quality, speed, and cost together. |[Quick start guide](agent-plan-enterprise-get-started.md) |
|skylark\-embedding\-vision |A multimodal embedding model that supports both image and text input. |[Embedding models](agent-plan-enterprise-vectorized-models.md) |
|dola\-seedream\-5.5 |Doubao Seedream 5.5 is Doubao's latest image creation model. It improves precise editing across multiple turns and supports native RGBA image generation. It provides finer layer decomposition, outputs up to 1 base image and 99 layers, and provides rich\-text OCR information. |[Video and image generation models](agent-plan-enterprise-visual-models.md) |
|dola\-seedream\-5.0\-flash |Designed for high\-precision image generation, with capabilities such as interactive editing, layer decomposition, and native multilingual generation. Seedream 5.0 Flash generates images faster at a lower price, making it suitable for latency\-sensitive and cost\-sensitive workloads. |[Video and image generation models](agent-plan-enterprise-visual-models.md) |
|dola\-seedream\-5.0\-pro |Designed for high\-precision image generation, with more precise control over positions and elements. It supports text\-to\-image generation and image generation with one or multiple reference images, as well as precise coordinate positioning and editing of arbitrary annotations through interactive editing. It also adds native text generation in 14 languages. |[Video and image generation models](agent-plan-enterprise-visual-models.md) |
|dreamina\-seedance\-2.5\-flash |A video generation model that supports text\-to\-video, first\-frame\-to\-video, first\-and\-last\-frame\-to\-video, omni reference\-to\-video, video editing, and video extension. It does not support Draft mode and supports 480p and 720p resolutions. |[Video and image generation models](agent-plan-enterprise-visual-models.md) |
|dreamina\-seedance\-2.5 |A new\-generation video creation model with comprehensive improvements in long\-form storytelling, omni reference capabilities, and editing. The duration of a single generation increases to 30 seconds, with support for multiple rounds of extension. A single generation can use up to 50 multimodal reference assets, with precise editing control based on timestamps. |[Video and image generation models](agent-plan-enterprise-visual-models.md) |
