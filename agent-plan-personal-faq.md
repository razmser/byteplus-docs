# About Agent Plan

## What is the difference between Agent Plan and Coding Plan?

Agent Plan is a new subscription package upgraded from Coding Plan. The differences are as follows:

|Comparison |Agent Plan |Coding Plan |
|---|---|---|
|Primary focus |A new subscription package for large model services focused on Agent scenarios, expanding into multimodal capabilities and Harness. |A subscription package for coding model services focused on coding scenarios for individual developers. |
|Models |Language models, embedding models, and visual models (image and video generation models) |Language models and embedding models |
|Harness |BytePlus Searchinfinity |/ |
|Base URL and API Key |Obtain the dedicated Base URL and API Key from the [Agent Plan console](https://ai.byteplus.com/ark/region:ap-southeast-1/openManagement?LLM=%7B%7D&advancedActiveKey=agentPlan). |Obtain the dedicated Base URL and API Key (ModelArk API Key) from the [Coding Plan console](https://ai.byteplus.com/ark/region:ap-southeast-1/openManagement?LLM=%7B%7D&advancedActiveKey=subscribe). |
|Subscription tiers |4 tiers to choose from |2 tiers |
|Billing |Usage is deducted in Agent Fuel Points (AFP), with clearly visible quota usage. |Estimated model request count |

## How do I disable data authorization?

If you want to disable data authorization after enabling it, submit [Ticket](https://console.byteplus.com/workorder/create?step=2&SubProductID=P00001514).
